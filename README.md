# CODTECH C Language Tasks

Submission-ready C programs for CODTECH Internship Tasks.

## Tasks Included
- **Task 1:** File Handling (Create/Write/Append/Read)
- **Task 2:** Singly Linked List (Insert/Delete/Traverse)
- **Task 3:** Simple Lexical Analyzer (Keywords/Identifiers/Operators)
- **Task 4:** Run Length Encoding (RLE) Compression + Decompression

## How to Run (VS Code / Terminal)

### Windows (MinGW)
```bash
gcc task1_file_handling.c -o task1
./task1
```

### Linux/macOS
```bash
gcc task1_file_handling.c -o task1
./task1
```

(Repeat similarly for other tasks.)
